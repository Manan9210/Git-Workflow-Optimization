Quick interpretation

Workflow descriptions

Git Flow

Uses long-lived branches such as main and develop, plus feature, release and hotfix branches. It provides structure but can add process overhead.

GitHub Flow

Uses a main branch and short-lived feature branches. Changes are reviewed through pull requests and merged after checks pass.

Trunk-Based Development

Developers integrate small changes frequently into a shared main branch, often using short-lived branches and automated tests.
